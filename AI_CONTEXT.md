# AI_CONTEXT

## Product Understanding

Building a simplified Splitwise clone.

Core features:

* Authentication
* Groups
* Expense splitting
* Balances
* Settlements
* Expense comments/chat

## Tech Stack

### Frontend

* React
* Tailwind CSS

### Backend

* Django
* Django REST Framework (DRF)

### Database

* PostgreSQL

### Deployment

* Vercel (Frontend)
* Render (Backend)
